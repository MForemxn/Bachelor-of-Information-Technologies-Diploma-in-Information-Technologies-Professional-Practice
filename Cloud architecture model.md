## ONE SENTENCE SUMMARY:

The cloud architecture model defines the structural components and services used to deliver scalable, on-demand computing over [[the internet]].

## OVERVIEW:

A cloud architecture model describes how various components of cloud computing—such as storage, compute, networking, and services—are structured and interact within a cloud environment. It typically consists of front-end interfaces (e.g. web browsers or mobile apps), back-end infrastructure (e.g. servers, storage), and a management platform that orchestrates resource allocation and service delivery. Cloud architecture supports [[models]] like public, private, hybrid, and multi-cloud, each offering varying levels of control, [[security]], and [[scalability]]. The most common service [[models]] include [[Infrastructure as a Service (IaaS)]], [[Platform as a Service (PaaS)]], and [[Software as a Service (SaaS)]]. These [[models]] abstract and automate infrastructure, reducing the need for manual hardware management. Key principles in cloud architecture include elasticity, fault tolerance, [[security]], and automation. This model underpins a wide range of applications from enterprise IT to mobile services and [[artificial intelligence]].

## MAIN POINTS:

1. Cloud architecture includes front-end, back-end, and orchestration layers.
    
2. It enables delivery of computing services via internet-based infrastructure.
    
3. Supports public, private, hybrid, and multi-cloud deployments.
    
4. Enables elasticity for scaling resources up or down on demand.
    
5. Service [[models]] include IaaS, PaaS, and SaaS.
    
6. Automates deployment and management through orchestration tools.
    
7. Promotes fault tolerance and high [[availability]].
    
8. Facilitates secure access to distributed resources.
    
9. Allows global accessibility and performance optimisation.
    
10. Forms the foundation for digital transformation in modern enterprises.
    

## TAKEAWAYS:

1. Cloud architecture abstracts infrastructure for flexible, scalable service delivery.
    
2. It supports diverse deployment and service [[models]].
    
3. Automation and orchestration reduce complexity and boost efficiency.
    
4. Built-in resilience and [[security]] are core design principles.
    
5. It enables modern, agile, and globally distributed applications.
